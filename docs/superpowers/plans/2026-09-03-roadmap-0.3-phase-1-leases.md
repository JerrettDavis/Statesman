# ROADMAP 0.3 Phase 1: Leases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `IStateLeaseProvider`/`IStateLease` as the second capability under Phase 0's
negotiation convention, implement it for Redis and EF Core, wire `StatesmanRuntime.MaintainAsync`
to acquire a per-store lease before running interval maintenance (falling back to today's
per-process behavior when a store doesn't support leases), and let `TieredStateLedgerStore` forward
capability discovery to whichever of its tiers can back it.

**Architecture:** `IStateLeaseProvider : IStateCapability` with `AcquireAsync(leaseId, ttl, ct) :
ValueTask<IStateLease?>`; `IStateLease : IAsyncDisposable` with `RenewAsync(ttl, ct) :
ValueTask<bool>`. A new `IStateCapabilityProvider` interface (deliberately NOT extending
`IStateCapability` — it is a forwarding mechanism, not a capability) lets a wrapping store answer
`TryGetCapability` on behalf of whichever inner store actually implements it;
`StateCapabilityExtensions.TryGetCapability<T>` consults it only after its own direct cast fails.
`StatesmanRuntime.MaintainAsync` groups due handles by `Manifest.Store`, resolves each store, and
gates that group's refresh behind a lease when the store supports one.

**Tech Stack:** .NET 10, xUnit v3, StackExchange.Redis 3.1.31, EF Core (Sqlite provider in tests),
existing `Statesman.Testing` harness (`StatesmanTestHarness`, `ManualTimeProvider`).

**Spec:** `docs/superpowers/specs/2026-09-03-roadmap-0.3-distributed-coordination-design.md`
(Phase 1 section and the "Capability forwarding through wrapping stores" addendum — read both
before starting; this plan corrects one architectural detail the spec got wrong, documented in
Task 2 below, and that correction should be reflected back into the spec once this phase lands).

## Global Constraints

- Target framework: `net10.0`. `Nullable`/`ImplicitUsings` enabled repo-wide;
  `TreatWarningsAsErrors=true`. New public capability interfaces get a `///` doc comment matching
  existing style (see `IStateLedgerReplica` in `src/Statesman.Abstractions/Ledger.cs:255-258`).
- Every text file must end with a trailing newline; `.cs` files have no trailing whitespace and
  never contain the literal substrings `TODO`, `FIXME`, or `NotImplementedException`
  (`NotSupportedException` is fine). Every `.csproj` must be listed in `Statesman.slnx`. Run
  `python3 eng/validate.py --report artifacts/static-validation.txt` before each commit and confirm
  no new findings beyond the pre-existing, gitignored `.remember/*` warnings.
- **No `Microsoft.Extensions.Logging` (or any new) dependency in the core `Statesman` package.**
  It currently depends on nothing but `Statesman.Abstractions` (`src/Statesman/Statesman.csproj`) —
  that zero-dependency property is deliberate and this phase preserves it. Maintenance degradation
  is tracked via an internal in-memory set, mirroring the existing (also internal, also untested
  directly) `_maintenanceFailures`/`MaintenanceFailures` pattern in `StatesmanRuntime.cs:12,47` —
  do not add a new logging call or package reference to make it "logged."
- **No new `[InternalsVisibleTo]`.** The repo has zero `InternalsVisibleTo` declarations today —
  internal runtime state is verified through public-API-observable behavior in tests, not by
  reaching into internals from a test assembly. Follow that convention: test the degraded-mode
  *behavior* (refresh still runs) via loader call counts, not by asserting on
  `DegradedMaintenanceStores` from a test.
- Redis-dependent tests must skip cleanly (via `Assert.SkipUnless`, xUnit v3's dynamic-skip API)
  when no live Redis is reachable, rather than fail — Windows/macOS CI legs and local dev without
  Redis running must stay green. A dedicated CI job runs them for real against a service container
  on Linux (Task 3).
- Lease TTL for runtime-internal maintenance coordination is a fixed constant
  (`TimeSpan.FromSeconds(30)`) for this phase — no new DI/options configuration surface. Adding
  configurability later is source-compatible and out of scope here (YAGNI).

public static bool TryGetCapability<TCapability>(
    this IStateLedgerStore store,
    [NotNullWhen(true)] out TCapability? capability)
    where TCapability : class, IStateCapability
{
    ArgumentNullException.ThrowIfNull(store);

    capability = store as TCapability;
    if (capability is not null)
    {
        return true;
    }

    if (store is IStateCapabilityProvider provider &&
        provider.TryGetCapability(typeof(TCapability), out object? forwarded))
    {
        capability = forwarded as TCapability;
        return capability is not null;
    }

    return false;
}

### Task 2: Lease-gated `StatesmanRuntime.MaintainAsync`

**Correction to the spec:** the spec's Phase 1 section says `StatesmanHostedService` acquires the
lease. That is architecturally wrong: `IStatesman` (the public interface `StatesmanHostedService`
holds) exposes no store reference, and a single root is not backed by one store — each
`StateHandle<T>` resolves its own store independently via `Manifest.Store`
(`src/Statesman/Runtime/StateHandle.cs:52`), a plain string, so different state keys under the same
root can live in different stores. Leasing must happen inside `StatesmanRuntime.MaintainAsync`,
grouped by store name. `StatesmanHostedService` itself needs **no changes** — it keeps calling
`root.MaintainAsync(stoppingToken)` exactly as today
(`src/Statesman.Extensions.Hosting/StatesmanHostingExtensions.cs:81`).

Replace `MaintainAsync` (currently `StatesmanRuntime.cs:301-310`) with:

```csharp
public async ValueTask MaintainAsync(CancellationToken cancellationToken = default)
{
    ThrowIfDisposed();
    DateTimeOffset now = TimeProvider.GetUtcNow();
    IStateHandleInternal[] due = _handles.Values.Where(handle => handle.IsMaintenanceDue(now)).ToArray();

    await Task.WhenAll(due
        .GroupBy(handle => handle.Manifest.Store)
        .Select(group => MaintainStoreGroupAsync(group.Key, group.ToArray(), cancellationToken)))
        .ConfigureAwait(false);
}

private async Task MaintainStoreGroupAsync(
    string storeName, IStateHandleInternal[] handles, CancellationToken cancellationToken)
{
    IStateLedgerStore store = Stores.Resolve(storeName);
    bool hasLeaseProvider = store.TryGetCapability(out IStateLeaseProvider? leases);

    // The lease's `await using` scope MUST cover the refresh call below, not just the
    // acquire-and-check. Scoping it to an `if` block that ends before the refresh means the
    // lease is released before the work it's supposed to protect even begins — two racing
    // processes both acquire-and-immediately-release, then both refresh concurrently, which is
    // exactly what the lease exists to prevent. Declaring it here, at the top level of the
    // method body, makes its scope the rest of the method, including the refresh below.
    await using IStateLease? lease = hasLeaseProvider
        ? await leases!.AcquireAsync($"{Id}:{storeName}:maintenance", MaintenanceLeaseTtl, cancellationToken).ConfigureAwait(false)
        : null;

    if (hasLeaseProvider)
    {
        if (lease is null)
        {
            return;
        }
    }
    else
    {
        _degradedMaintenanceStores.TryAdd(storeName, 0);
    }

    await Task.WhenAll(handles.Select(handle =>
        handle.RefreshUntypedAsync(
            new StateWriteOptions { Source = "interval" },
            cancellationToken).AsTask())).ConfigureAwait(false);
}
```

This preserves today's behavior exactly for the common case of one store (all due handles form a
single group, refreshed concurrently, no observable change) while adding per-store-group lease
gating for the multi-store case, and — critically — holds the lease for the full duration of that
group's refresh. `_degradedMaintenanceStores` is deliberately internal and
deliberately not asserted on directly by any test in this task — it mirrors the existing
`_maintenanceFailures` field (line 12), which is equally internal and equally untested directly
today; both exist for future health-check/observability consumers (ROADMAP 0.2), not for this
phase's test suite.

{
    private const string RenewScript = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("pexpire", KEYS[1], ARGV[2])
        end
        return 0
        """;

        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        end
        return 0
        """;

    private readonly IDatabase _database;
    private readonly RedisKey _key;
    private readonly string _token;
    private int _disposed;

    public RedisLease(IDatabase database, RedisKey key, string token)
    {
        _database = database;
        _key = key;
        _token = token;

        if (ttl <= TimeSpan.Zero)
        {
            throw new ArgumentOutOfRangeException(nameof(ttl), "A lease TTL must be greater than zero.");
        }

        cancellationToken.ThrowIfCancellationRequested();
        RedisResult result = await _database
            .ScriptEvaluateAsync(RenewScript, [_key], [_token, (long)ttl.TotalMilliseconds])
            .ConfigureAwait(false);
        return (long)result == 1;
    }

    public async ValueTask DisposeAsync()

        {
            return;
        }

        await _database.ScriptEvaluateAsync(ReleaseScript, [_key], [_token]).ConfigureAwait(false);
    }
}

internal sealed class EntityFrameworkLease<TContext> : IStateLease
    where TContext : StatesmanLedgerDbContext
{
    private readonly IDbContextFactory<TContext> _factory;
    private readonly string _leaseId;
    private readonly string _token;
    private readonly TimeProvider _timeProvider;
    private int _disposed;

    public EntityFrameworkLease(
        IDbContextFactory<TContext> factory, string leaseId, string token, TimeProvider timeProvider)
    {
        _factory = factory;
        _leaseId = leaseId;
        _token = token;
        _timeProvider = timeProvider;
    }

    public async ValueTask<bool> RenewAsync(TimeSpan ttl, CancellationToken cancellationToken = default)
    {
        if (ttl <= TimeSpan.Zero)
        {
            throw new ArgumentOutOfRangeException(nameof(ttl), "A lease TTL must be greater than zero.");
        }

        await using TContext context = await _factory.CreateDbContextAsync(cancellationToken).ConfigureAwait(false);
        StatesmanLedgerLease? existing = await context.StatesmanLeases
            .SingleOrDefaultAsync(value => value.LeaseId == _leaseId, cancellationToken)
            .ConfigureAwait(false);
        if (existing is null || existing.Token != _token)
        {
            return false;
        }

        existing.ExpiresAt = _timeProvider.GetUtcNow() + ttl;
        await context.SaveChangesAsync(cancellationToken).ConfigureAwait(false);
        return true;
    }

    public async ValueTask DisposeAsync()
    {
        if (Interlocked.Exchange(ref _disposed, 1) != 0)
        {
            return;
        }

        await using TContext context = await _factory.CreateDbContextAsync().ConfigureAwait(false);
        StatesmanLedgerLease? existing = await context.StatesmanLeases
            .SingleOrDefaultAsync(value => value.LeaseId == _leaseId)
            .ConfigureAwait(false);
        if (existing is not null && existing.Token == _token)
        {
            context.StatesmanLeases.Remove(existing);
            await context.SaveChangesAsync().ConfigureAwait(false);
        }
    }
}

`MaintainAsync` will propagate for that group only). If this proves too strict in practice, catching
`DbUpdateConcurrencyException` and returning `null` is a safe, source-compatible follow-up — not
required for this task's tests to pass.

public bool TryGetCapability(Type capabilityType, out object? capability)
{
    ArgumentNullException.ThrowIfNull(capabilityType);

    if (capabilityType.IsInstanceOfType(_hot))
    {
        capability = _hot;
        return true;
    }

    if (_hot is IStateCapabilityProvider hotForwarder && hotForwarder.TryGetCapability(capabilityType, out capability))
    {
        return true;
    }

    if (capabilityType.IsInstanceOfType(_cold))
    {
        capability = _cold;
        return true;
    }

    if (_cold is IStateCapabilityProvider coldForwarder && coldForwarder.TryGetCapability(capabilityType, out capability))
    {
        return true;
    }

    capability = null;
    return false;
}
